# Referensi desain iRent

Buka [index.html](index.html) untuk melihat dan memfilter 36 halaman desktop/mobile dari [workspace Stitch terbaru](https://stitch.withgoogle.com/projects/7448049823013098704). Klik preview untuk HTML, atau **Gambar penuh** untuk PNG. Galeri dapat dibuka langsung dari filesystem.

- `previews/`: ekspor terbaru; kode A/MA untuk admin, C/MC untuk pelanggan, M01/M02 adalah varian mobile tambahan.
- `screens.latest.json`: pemetaan kode ke screen Stitch dan file lokal.
- `DESIGN.md`: salinan aturan desain terbaru. Sumber utama tetap [DESIGN.md di root](../DESIGN.md); sinkronkan salinan bila aturan berubah.
- `archive/legacy-previews/`: tujuh preview lama untuk arsip; tidak digunakan sebagai acuan implementasi.

Acuan implementasi aktif: [aturan visual utama](../DESIGN.md) dan [peta layar redesign](../STITCH_REDESIGN.md). Gunakan hanya layar FIX dari workspace redesign di atas.

Gunakan Poppins, canvas putih/abu, ruang luar yang cukup, hierarki ukuran teks, foto item yang jelas, dan informasi bertahap sesuai guide. Ekspor Stitch merupakan referensi visual; beberapa card masih padat. Implementasi harus mengikuti aturan terbaru dan API/PRD, bukan menyalin semua teks atau data contoh. Foto contoh perlu diganti dengan foto inventaris sebenarnya.
