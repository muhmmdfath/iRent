Apakah 4 GB kuat?

Layak sebagai kapasitas awal, bukan jaminan untuk semua jumlah pengunjung. Beban dipengaruhi aktivitas bersamaan, foto, laporan, dan pengaturan server. Belum ada hasil uji beban produksi iRent untuk menetapkan batas pengunjung.

Tambahan biaya promo ke 8 GB adalah Rp35.000 setara per bulan. Peningkatan dipertimbangkan bila server sering kehabisan memori, melambat saat ramai, atau penyimpanan mulai penuh. Penambahan kapasitas mengikuti prosedur provider dan dapat membutuhkan jeda layanan.

Kenapa bukan shared hosting biasa?

iRent menyimpan transaksi dan menjalankan pengingat otomatis, sehingga membutuhkan layanan yang mendukung aplikasi dan database kita. Shared hosting bisa dipakai jika paketnya mendukung seluruh kebutuhan tersebut; tidak semua paket mendukungnya. Untuk implementasi saat ini, satu VPS lebih mudah disesuaikan. Contohnya, Hostinger mengarahkan kebutuhan PostgreSQL ke VPS. Sumber provider.

Keputusan yang kami sarankan

Pilih satu VPS 4 GB + satu domain .com untuk menekan biaya awal. Seluruh aplikasi tetap dalam satu server. Siapkan backup data di luar server dan pemeriksaan berkala; peningkatan kapasitas dilakukan berdasarkan pemakaian nyata.

Biaya di atas adalah infrastruktur, tidak termasuk jasa setup/pemeliharaan, iklan Google, atau WhatsApp/OTP. Dokumen ini merupakan usulan, belum ada pembelian layanan. Rekomendasi kapasitas adalah perkiraan berdasarkan aplikasi iRent saat ini.
